## 🚀 GitHub Pages-ზე გამოქვეყნება (ნაბიჯ-ნაბიჯ)

### ნაბიჯი 1 — GitHub-ზე შეხვიდეთ
გადადით [github.com](https://github.com) და შეხვიდეთ თქვენს ანგარიშში.  
თუ ანგარიში არ გაქვთ — შექმენით უფასოდ.

### ნაბიჯი 2 — ახალი Repository შექმენით
1. დააჭირეთ **"+"** ღილაკს ზედა მარჯვენა კუთხეში
2. აირჩიეთ **"New repository"**
3. სახელი ჩაწერეთ: `rbili-aveji`
4. დატოვეთ **Public**
5. დააჭირეთ **"Create repository"**

### ნაბიჯი 3 — ფაილები ატვირთეთ
1. Repository-ში დააჭირეთ **"uploading an existing file"**
2. გადაათრიეთ ყველა ფაილი და საქაღალდე:
   - `index.html`
   - `css/` საქაღალდე
   - `js/` საქაღალდე
   - `images/` საქაღალდე
3. დააჭირეთ **"Commit changes"**

### ნაბიჯი 4 — GitHub Pages ჩართეთ
1. Repository-ში გადადით **Settings** (ზედა მენიუ)
2. მარცხენა გვერდზე დააჭირეთ **"Pages"**
3. **Source**-ის ქვეშ აირჩიეთ **"Deploy from a branch"**
4. Branch: **main** → folder: **/ (root)**
5. დააჭირეთ **Save**

### ნაბიჯი 5 — საიტი მზადაა! ✅
2-3 წუთში თქვენი საიტი ხელმისაწვდომი იქნება:
```
https://[თქვენი-username].github.io/rbili-aveji/
```
